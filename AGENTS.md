# EVENTMGdev

- Codex пишет код и принимает результат. Claude подключается через Harness только для независимого ревью и проверок в режиме чтения. Модель и границы проверки определяет Codex.
- Соблюдай ТЗ и эталон MGIMOdev в Figma. Пользовательские тексты на русском, данные вымышленные.
- Проверяй роли и владельца записей на сервере. Секреты храни только в окружении.
- Веди изменения в пределах своей задачи и указывай фактически выполненные проверки.
- При планировании новых функций ориентируйся на [план продукта](PRODUCT_PLAN.md). Для каждой функции описывай задачу пользователя, отмечай рабочие гипотезы и фиксируй критерий готовности.
- Проверяй каждый экран на телефоне 360 px и ПК 1440 px в обеих темах. Для ПК используй существующий десктопный кадр Figma, а для остальных экранов адаптируй мобильный макет.
- Перед приёмкой интерфейса открой эталонные кадры Figma и сравни их со скриншотами приложения. Проверь композицию, порядок блоков, отступы, типографику, иконки, состояния и цвета. Отдельно отмечай экраны и состояния, для которых визуальная сверка ещё не проведена.
