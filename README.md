# EVENTMGdev

Конкурсный прототип «Цифровой деканат».

[Инструкция по размещению на хостинге](DEPLOYMENT.md).

## Локальный запуск

Нужны Node.js 22.12+ и PostgreSQL. Скопируйте `.env.example` в `.env`, укажите доступ к базе и сгенерируйте уникальный `BETTER_AUTH_SECRET` (например, `openssl rand -hex 32`). Задайте три отдельных пароля от 8 символов для двух демо-студентов и сотрудника. `DEMO_ACCESS=true` включает быстрый вход для двух студентов.

```bash
npm ci
npm run db:migrate
npm run db:seed
npm run dev
```

Откройте http://localhost:3000. Если порт занят, задайте другой порт в `BETTER_AUTH_URL` и запустите `npm run dev -- --port 3100`. Демо-логины студентов — `anna` и `maxim`. Учётная запись сотрудника `irina` входит через общую форму. Пароли для начального наполнения задаются локально в `.env`.

`npm run db:seed` готовит четыре демонстрационные заявки, обращение № М-0172 и уведомление с памяткой. У Анны можно посмотреть № 0418 «В работе» и № 0409 для получения в деканате. У Максима доступны справка с PDF и отклонённая заявка. Повторное наполнение сохраняет историю уже созданных заявок и переписки.

`npm run typecheck` проверяет типы. `npm run build` собирает приложение. Пользовательские данные возвращаются для текущей сессии через `GET /api/v1/me`.

[Эталон интерфейса MGIMOdev](https://www.figma.com/design/WOttTMwG16ZQHpIZ0tO0k9/MGIMOdev)

## Заявки и справки

Студент подаёт и отслеживает заявки в разделе «Заявки и справки». Сотрудник обрабатывает их в разделе «Заявки» своего кабинета. Электронный PDF хранится вместе с заявкой в PostgreSQL и выдаётся через маршрут с проверкой владельца. Для загрузки установлен лимит 10 МБ.

## ИИ-помощник

Сотрудник настраивает API в разделе «ИИ-помощник». По умолчанию используется OpenRouter. Выберите поставщика, при необходимости измените базовый HTTPS-адрес и введите ключ. Приложение автоматически выбирает OpenAI-совместимый API или Messages. Список моделей загружается с указанного API. После сохранения чат и черновики заявок используют общее подключение. Приложение хранит ключ в зашифрованном виде. Здесь же сотрудник настраивает стиль чата и загружает документы в базу знаний. База знаний принимает PDF, DOCX, TXT, JPG и PNG до 50 МБ. На фотографиях и страницах PDF без текстового слоя распознаётся русский и английский текст. Помощник прикладывает ссылку на документ к ответам о правилах вуза.

Для переноса стартовой базы на другую установку скачайте оригиналы из [реестра МГИМО](https://mgimo.ru/sveden/document/) с именами `000453.pdf`, `004776.pdf`, `004777.pdf`, `000457.pdf` и `003143.pdf`. После миграций выполните `npx tsx scripts/import-mgimo-knowledge.ts /путь/к/каталогу`. Повторный запуск пропустит уже загруженные файлы.

Студент и сотрудник могут выбрать готовую аватарку или загрузить свою в профиле.

## Уведомления

К объявлению можно прикрепить один PDF, JPG или PNG до 10 МБ. Файл доступен в карточке уведомления студентам из выбранной аудитории.

## Студенты и расписание

Сотрудник создаёт учебный аккаунт в разделе «Студенты» с обязательными полями фамилии, имени и отчества. Временный пароль выдаётся в ответе на создание и хранится в базе как хеш. Студент задаёт собственный пароль при первом входе. Учебные записи новому аккаунту добавляются по мере наполнения.

Расписание и уведомления об изменениях доступны студентам выбранной группы и аудитории. При добавлении занятия сотрудник выбирает обычные или демо-аккаунты. В демо стартовая дата — 16 ноября 2026 года. Команда `npm run db:seed` добавляет вымышленные занятия для групп Анны и Максима. Ссылка «В календарь» скачивает файл ICS без отменённых занятий.
