# Размещение «Цифрового деканата» на хостинге

Приложение запускается как сервер Next.js. Выберите хостинг с Node.js 24 и PostgreSQL, где можно задать переменные окружения и запустить миграции. Подключите ветку `main` из GitHub или распакуйте архив исходников. Команды выполняются из корня проекта.

## Настройки хостинга

| Переменная | Значение |
| --- | --- |
| `DATABASE_URL` | Строка подключения к PostgreSQL, выданная хостингом. |
| `BETTER_AUTH_URL` | Публичный адрес приложения с HTTPS, например `https://deanery.example.org`. |
| `BETTER_AUTH_SECRET` | Сгенерируйте один раз командой `openssl rand -hex 32` и сохраните в секретах хостинга. От этого значения зависит доступ к сохранённому ключу ИИ. |
| `DEMO_ACCESS` | `false` для обычного кабинета. `true` показывает быстрый вход для созданных демо-студентов. |
| `DEMO_STAFF_PASSWORD` | Уникальный пароль первого сотрудника для начального наполнения базы. |
| `DEMO_ANNA_PASSWORD`, `DEMO_MAXIM_PASSWORD` | Отдельные пароли демо-студентов. Нужны при развёртывании демонстрационной базы. |

Для загрузки документов базы знаний проверьте, что хостинг принимает запросы размером до 51 МБ с учётом упаковки файла. Если платформа ограничивает размер запроса, этот лимит будет действовать и в кабинете.

## Сборка и запуск

1. Установите зависимости и соберите приложение.

   ```bash
   npm ci --include=dev
   npm run build
   ```

   Если хостинг запрашивает одну команду сборки, используйте `npm ci --include=dev && npm run build`. На этапе сборки задайте `BETTER_AUTH_URL` и `BETTER_AUTH_SECRET`.

2. Перед запуском новой версии примените миграции отдельной командой.

   ```bash
   npm run db:migrate
   ```

   Для существующей базы сначала сделайте резервную копию. Миграция отчеств использует сохранённые ФИО. Если в старой базе есть учётные записи без полного ФИО, внесите отчества до миграции.

3. Если база пустая, выберите один способ начального наполнения.

   - **Обычный кабинет** — `npm run db:bootstrap-staff`. Команда создаёт сотрудника `irina`. Повторный запуск сохраняет его текущий пароль. Новых студентов сотрудник создаёт в кабинете.
   - **Демонстрация** — `npm run db:seed`. Команда создаёт сотрудника `irina`, студентов `anna` и `maxim` и добавляет демонстрационные данные. Используйте отдельную базу для демонстрации.

4. Настройте команду запуска.

   ```bash
   npm run start -- --hostname 0.0.0.0
   ```

   Порт берётся из переменной `PORT`, которую обычно задаёт хостинг. При её отсутствии используется порт 3000.

## После запуска

- Войдите под сотрудником и настройте подключение к модели в разделе «ИИ-помощник».
- Загрузите утверждённые документы через базу знаний или импортируйте стартовые документы МГИМО по [инструкции проекта](README.md#ии-помощник).
- Проверьте вход через HTTPS, разграничение доступа, отправку заявки и ответы ИИ со ссылками на документы. Затем пройдите основные сценарии на физических iPhone и Android.

Архив исходников содержит код, статические ресурсы и миграции. Учётные записи, данные кабинета и документы, загруженные в базу знаний, хранятся в PostgreSQL. Для их переноса используйте отдельную резервную копию базы.
